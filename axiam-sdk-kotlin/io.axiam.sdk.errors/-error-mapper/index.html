ErrorMapper

object ErrorMapper

Central HTTP-status → error-type mapper (CONTRACT.md §2). The single source of truth for the taxonomy so no call site can drift from the contract's status table:

StatusType
401AuthError
403, 409AuthzError
400/408/429/5xx/otherNetworkError

sanitize is the ONLY path from a live Response into a NetworkError: it redacts every header not on a small allowlist and returns a lightweight string summary — the live response (with its unredacted headers) is never retained on the exception.
