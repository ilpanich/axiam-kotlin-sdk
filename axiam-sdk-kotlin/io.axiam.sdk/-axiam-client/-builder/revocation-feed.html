fun revocationFeed(feed: RevocationFeed): <Error class: unknown class>

CONTRACT.md §10.4 (contract 1.44) — the optional session-revocation feed the §10 guard (AxiamClient.verifySession) consults after every §10.1 rule has passed.

Unset by default, and left unset this client behaves exactly as it did before 1.44: a revoked session's access token verifies locally until it expires, which is the §10.2 posture the feed narrows rather than replaces.

It is never a control — it can only ever turn an accept into a reject, it is never consulted for a token that names no session, and a feed that cannot be read denies nothing. Share one instance across the guards that should poll once between them rather than once each.
