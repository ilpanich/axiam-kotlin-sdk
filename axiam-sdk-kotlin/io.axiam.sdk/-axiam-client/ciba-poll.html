cibaPoll

suspend fun cibaPoll(params: CibaPollParams): OidcTokenSet

POST /oauth2/token with grant_type=urn:openid:params:grant-type:ciba (CIBA Core §10.1, CONTRACT.md §33.1) — one token request.

The answers of §33.3 rule 6 surface as io.axiam.sdk.errors.OAuthProtocolError: authorization_pending and slow_down (non-terminal), access_denied and expired_token (terminal, and told apart by isAccessDenied / isExpiredToken), invalid_grant. A 200 is validated like every other grant's token response (§12.4; no nonce).

Retried per §16 within the call on a transport failure, 5xx, 408 or a bodiless 429; never on a protocol answer or another 4xx. A 5xx is transient whatever its body — AXIAM's own 500 {"error":"server_error"} included — and surfaces as a NetworkError, never an OAuthProtocolError (§33.4, §34.2 P8). Store the returned tokens before anything else: a request is redeemed once, and a second cibaPoll for it is invalid_grant (§33.7 rule 7).

Return

the token set; not adopted as this client's credential

Parameters

params

the auth_req_id and routing
