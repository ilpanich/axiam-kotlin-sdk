suspend fun webauthnRegisterStart(): WebauthnChallenge

POST /api/v1/auth/webauthn/register/start (CONTRACT.md §24.1) — begin enrolling a passkey for the signed-in user.

Requires a session, and refuses client-side with no wire call when there is none — the shape §1.1 rule 3 requires of getUserInfo.

The returned options are the server's, untouched (§24.0). A 503 here means the tenant's attestation policy needs FIDO metadata the server cannot reach: a configuration state, not a transient one, and §24.4 rule 2 deliberately does not retry it.
