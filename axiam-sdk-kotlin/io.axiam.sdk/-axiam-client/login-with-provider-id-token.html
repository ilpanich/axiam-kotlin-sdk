loginWithProviderIdToken

suspend fun loginWithProviderIdToken(params: ProviderIdTokenLoginParams): OidcTokenSet

Native sign-in with a provider ID token (CONTRACT.md §37, contract 1.65): one POST /oauth2/token with grant_type=urn:axiam:params:oauth:grant-type:provider-id-token.

For an app that holds the ID token a Google, Apple or Facebook (Limited Login) SDK produced. A public client (no oidcClientSecret) is the normal caller and is not refused. Never retried — the provider token is single-use across the whole deployment — and invalid_grant is one generic answer that is surfaced as received, never refined: obtain a fresh provider token with a fresh nonce (nativeNonce) and try again. Neither the provider token nor the raw nonce is logged or kept. The result is not adopted as this client's own credential. See ProviderIdTokenLoginParams.
