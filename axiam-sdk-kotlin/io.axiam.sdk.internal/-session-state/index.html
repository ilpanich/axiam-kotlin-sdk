SessionState

class SessionState(cookieManager: CookieManager, baseUrl: String, tenantId: String, configuredOrgSlug: String?, configuredOrgId: UUID?)

Per-io.axiam.sdk.AxiamClient session/cookie/CSRF/tenant/org state (CONTRACT.md §3/§4/§5).

Holds no token copy of its own: cachedAccessToken always reads the live axiam_access cookie from the shared CookieManager, which OkHttp's JavaNetCookieJar keeps in sync on every response — avoiding a second, potentially-stale in-memory token.

doHttpRefresh is the suspend function the RefreshGuard invokes: it performs the real POST /api/v1/auth/refresh, whose body carries the tenant/org UUIDs decoded (unverified) from the current access token. That decode is only ever an operational hint (tenant/org resolution, near-expiry), never an authorization decision — JwksVerifier owns signature verification.

doHttpRefresh
Link copied to clipboard
suspend fun doHttpRefresh(actingTenant: UUID? = null): TokenPair

Performs POST /api/v1/auth/refresh (CONTRACT.md §1). The body carries the tenant/org UUIDs resolved from the current access token's claims (the real handler requires both). Runs on Dispatchers.IO; the refresh path is special-cased by the header interceptor so this can never recursively trigger a nested refresh.
