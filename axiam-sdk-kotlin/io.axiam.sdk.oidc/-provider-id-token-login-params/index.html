ProviderIdTokenLoginParams

data class ProviderIdTokenLoginParams(val provider: String, val idToken: Sensitive<String>, val nonce: Sensitive<String>, val scopes: List<String>? = null, val resource: String? = null, val tenantId: String? = null, val configuration: OidcConfiguration? = null)

Arguments to loginWithProviderIdToken (CONTRACT.md §37, contract 1.65): native sign-in with the ID token a Google, Apple or Facebook (Limited Login) SDK produced on the device.

idToken and nonce are credentials (§37.6, §37.2 rule 12): wrapped in Sensitive, never logged, never kept after the call returns. Hold the raw nonce only for the length of the attempt.
