ResourceSet

data class ResourceSet(val name: String, val id: String? = null, val type: String? = null, val resourceScopes: List<String> = emptyList())

A UMA resource set — an AXIAM resource seen through the Protection API (CONTRACT.md §20.1).

id is the AXIAM resource id, not a parallel identifier: the same UUID is directly usable as the RequestedPermission.resourceId of a later ticket request, and as the resource id anywhere else in this SDK.
