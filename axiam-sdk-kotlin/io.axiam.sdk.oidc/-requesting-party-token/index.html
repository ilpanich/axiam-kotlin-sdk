RequestingPartyToken

data class RequestingPartyToken(val accessToken: Sensitive<String>, val tokenType: String, val expiresIn: Long)

The result of the UMA ticket grant (§20.1).

There is no refreshToken property, and that is deliberate (§20.2 rule 5). The grant issues none, so an RPT cannot outlive the ticket that authorised it; an application that wants a fresh one re-runs the grant. This result never enters the §9 single-flight refresh guard — there is nothing to refresh.
