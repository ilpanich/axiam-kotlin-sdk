mtls_endpoint_aliases

val mtls_endpoint_aliases: MtlsEndpointAliases? = null

RFC 8705 §5 endpoint aliases for a deployment that terminates mutual TLS on a host other than the issuer's own (contract 1.40, §21.3 rule 2).

null means "no separate host", not "mTLS unsupported": a deployment running client_auth = optional on one listener serves both populations at the conventional endpoints and correctly publishes nothing here. A client treating absence as an error would refuse the most common mTLS topology AXIAM ships. The server omits the key rather than serialising null.
