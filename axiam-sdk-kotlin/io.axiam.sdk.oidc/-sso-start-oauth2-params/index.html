data class SsoStartOauth2Params(val federationConfigId: String, val redirectUri: String, val tenantId: String? = null, val tenantSlug: String? = null, val orgId: String? = null, val orgSlug: String? = null)

Arguments to ssoStartOauth2 (POST /api/v1/auth/federation/oauth2/start).

Deliberately identical in shape to SsoStartParams, because the wire schemas are: OAuth2StartRequest and OidcStartRequest differ in name only. There is NO PKCE field, and there must not be — the verifier is generated and held server-side (§12.1 note 11).
