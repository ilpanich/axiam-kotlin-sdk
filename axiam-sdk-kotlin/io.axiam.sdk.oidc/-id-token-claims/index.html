IdTokenClaims

data class IdTokenClaims(val iss: String, val sub: String, val aud: List<String>, val exp: Long, val iat: Long, val nbf: Long? = null, val nonce: String? = null, val azp: String? = null, val extra: Map<String, Any?> = emptyMap())

The decoded, ALREADY-VALIDATED ID-token claim set carried by OidcTokenSet.idClaims (CONTRACT.md §12.1).

Claim names are kept verbatim in their JWT/OIDC spelling (iss, sub, aud, …) rather than Kotlin's usual camelCase field-naming, and extra preserves any further claim the server sends (e.g. email, preferred_username) — the ID token's full claim set is not enumerated by openapi.json, so unknown claims MUST be preserved and MUST NOT be rejected (§12.1).
