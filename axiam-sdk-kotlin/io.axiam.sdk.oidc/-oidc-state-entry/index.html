OidcStateEntry

data class OidcStateEntry(val state: String, val nonce: String, val codeVerifier: Sensitive<String>, val redirectUri: String, val returnTo: String? = null)

The tuple an OidcStateStore holds for one in-flight login.

codeVerifier stays Sensitive while stored (§12.5: the verifier is secret for its whole lifetime, "including … in any OidcStateStore entry"), so serializing an entry — e.g. into a Redis-backed store — never emits the verifier by accident; a store implementation that needs to persist the value must call Sensitive.expose explicitly and is then responsible for protecting it at rest.
