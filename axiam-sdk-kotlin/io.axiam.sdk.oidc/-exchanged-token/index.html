ExchangedToken

data class ExchangedToken(val accessToken: Sensitive<String>, val issuedTokenType: String, val tokenType: String, val expiresIn: Long, val scope: String? = null)

The result of an exchange (wire schema TokenExchangeResponse, §15.1).

There is no refreshToken property, and that is deliberate (§15.2 rule 4). RFC 8693 issues none, so the type cannot represent one: an application that wants a fresh exchanged token re-runs the exchange. This result also never enters the §9 single-flight refresh guard — there is nothing to refresh.
