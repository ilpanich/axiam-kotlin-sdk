SsoCompleteResult

data class SsoCompleteResult(val userId: String, val sessionId: String, val expiresIn: Long, val redirectUri: String)

The result of ssoComplete (wire schema SsoLoginSuccessResponse).

Carries NO token material — the session arrives as Set-Cookie, so the §4 cookie jar (already wired into io.axiam.sdk.AxiamClient's shared OkHttpClient) is what actually captures it (§12.1 note 6).
