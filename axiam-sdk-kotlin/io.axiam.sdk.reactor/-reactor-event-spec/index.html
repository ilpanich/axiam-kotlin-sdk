ReactorEventSpec

data class ReactorEventSpec(val name: String, val interceptable: Boolean, val mutable: Boolean, val mutableFields: List<String>, val defaultFailurePolicy: FailurePolicy, val description: String)

One hookable event: its name, what a reactor may change, and what happens when the reactor does not answer (CONTRACT.md §22.5).

Mirrors the server's ReactorEventSpec in crates/axiam-core/src/models/reactor.rs, which is the single source of truth. The live copy is served at GET /api/v1/reactors/events; this one is here so a wire contract does not require a network call to be understood.
