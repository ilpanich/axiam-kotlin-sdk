canonicalEventBytes

fun canonicalEventBytes(body: ByteArray): ByteArray

The exact bytes an event was signed over: the received body with hmac_signature set to null in place.

Setting the value rather than removing the key is what makes these bytes a reactor body rather than a §8 one. The field keeps its position: kotlinx.serialization parses a JSON object into an insertion-ordered map and re-encodes it in that order, and numeric literals survive the round trip as their original text.

the canonical bytes
