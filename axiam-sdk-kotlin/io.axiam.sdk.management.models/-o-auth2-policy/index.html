OAuth2Policy

@Serializable
data class OAuth2Policy(val refreshReuseResponse: RefreshReuseResponse? = null)

OAuth 2.0 authorization-server behaviour that is a tenant's to decide (G-C, #818). A struct of its own rather than a field on TokenPolicy because it is not a lifetime, and so the resolved setting reads by its documented name, oauth2.refresh_reuse_response.

Every property is optional, so this is a SPARSE body: what you leave unset is left unchanged, and is omitted from the wire request entirely rather than sent as null (§27.4 rule 5). Naming the properties you mean to change is the whole API — there is no builder because Kotlin does not need one, and no way to accidentally send a field you did not name.

@SerialName(value = "refresh_reuse_response")
val refreshReuseResponse: RefreshReuseResponse?

What a refused refresh-token replay does besides refusing. Ordered: a tenant may move from refuse to revoke_session and never back while its organization's baseline is revoke_session. Published as a reference to the RefreshReuseResponse schema, so the two legal values reach the SDK generators as an enum (F4-W1-06, #823).
