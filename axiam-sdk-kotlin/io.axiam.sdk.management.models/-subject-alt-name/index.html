SubjectAltName

@Serializable(with = SubjectAltName.Companion.Serializer::class)
sealed interface SubjectAltName

A name to put in a Server certificate's subjectAltName. Stated explicitly in the request, never read from a CSR: a CSR asking for a subjectAltName extension is still refused. URI and e-mail names are not offered — nothing in AXIAM consumes them yet.

An EXTERNALLY TAGGED oneOf: the wire shape is {"dns": ...} or {"ip": ...} -- the key itself is the tag, not a shared discriminator field. kotlinx.serialization's built-in polymorphism always adds a discriminator PROPERTY, which cannot produce this shape, so SubjectAltName carries a hand-written KSerializer instead.
