@SerialName(value = "user_id")
val userId: String?

The user account a User certificate is issued for (#533), returned as the certificate's user_id. Optional; accepted only for cert_type: User, and it must name a user of this tenant that has not been deleted or erased. A metadata.user_id in the same request must agree with it. Revoking the account's certificates — directory linking, deletion, erasure — matches on it. Passed as a plain string, untyped (CONTRACT.md §27.11 rule 5, contract 1.62): the text of a UUID, sent exactly as given so that a value that is not one reaches the server and its 400 is surfaced. Never null on the wire: an assigned null is the same as leaving it unset.
