NativeLoginTrustRequest

@Serializable
data class NativeLoginTrustRequest(val clientIds: List<String>? = null, val enabled: Boolean? = null, val maxTokenAgeSecs: Long? = null)

Native sign-in trust (G-A): which ID tokens this provider issued to an app are accepted as a sign-in at the token endpoint. Mirrors the domain block on the wire, as TokenExchangeTrustRequest does, so an omitted member takes its documented default rather than failing deserialization. Only an OidcConnect provider may enable it.

Every property is optional, so this is a SPARSE body: what you leave unset is left unchanged, and is omitted from the wire request entirely rather than sent as null (§27.4 rule 5). Naming the properties you mean to change is the whole API — there is no builder because Kotlin does not need one, and no way to accidentally send a field you did not name.
