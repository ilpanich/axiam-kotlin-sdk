A tenant-level certificate for users, services, or IoT devices. Certificates are signed by the organization's CA. The private key is returned once on generation and never stored by AXIAM.

userId
Link copied to clipboard
@SerialName(value = "user_id")
val userId: @Serializable(with = UuidSerializer::class) UUID?

The user account a User certificate was issued for, in this tenant (#533); null for every other type, for a User certificate issued without one, and for every certificate issued before schema v98. What revoking a user's certificates matches on — directory linking, administrator deletion and Art. 17 erasure. A row with None is matched by the older convention instead (metadata.user_id, or a subject common name equal to the account's username or email); a row naming another account never is. It does not make the certificate authenticate as the user: a certificate authenticates only as the service account it is bound to.
