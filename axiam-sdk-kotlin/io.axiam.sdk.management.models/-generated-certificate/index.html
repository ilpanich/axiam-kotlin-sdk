chainPem
Link copied to clipboard
@SerialName(value = "chain_pem")
val chainPem: String? = null

The issuing chain, concatenated PEM, nearest issuer first. Present only when the signer returned one — which is the vault_pki case, where the root's certificate exists nowhere a client could fetch it from. For a CA AXIAM signed with itself the chain is the CA certificate, which GET .../ca-certificates/{id} already serves, so the field is omitted rather than restating it.
