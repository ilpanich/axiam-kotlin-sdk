The body of PUT /api/v1/network/policy: a replacement of the policy.

This body REPLACES rather than patches (§27.4 rule 5): what you do not carry over from a prior read is not preserved, it is overwritten. Every property is required and none defaults, so forgetting one is a compile error rather than a silent null on the wire. Read first, copy(), write back.
