ProtectedResourceMetadata

data class ProtectedResourceMetadata(val document: ProtectedResourceMetadataDocument, val metadataPath: String, val metadataUrl: String)

What Mcp.protectedResourceMetadata returns: the document, the path it is served at, and the URL that path resolves to.

metadataUrl exists so that the guard's resourceMetadataUrl option (CONTRACT.md §28.5) is fed from the helper that derived it rather than retyped — retyping is how the two come to disagree, and a challenge pointing at a document that is not this resource server's is worse than no challenge at all.
