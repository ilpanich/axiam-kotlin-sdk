TelemetryHook

fun interface TelemetryHook

A caller-supplied telemetry sink (CONTRACT.md §19).

Install one with AxiamClient.Builder.telemetryHook. It receives request start/end, §16 retry and §9 refresh events, so metrics can be wired without this module depending on any metrics library.

A hook that throws cannot fail the operation that fired it (§19.2 rule 2) — the dispatcher swallows it. That is a backstop, not a licence.
