NetworkSpec

data class NetworkSpec(val policy: ManagementManifest.NetworkPolicySpec? = null, val segments: List<ManagementManifest.NetworkSegmentSpec> = emptyList(), val profiles: List<ManagementManifest.NetworkProfileSpec> = emptyList())

The network section of a manifest (CONTRACT.md §27.6.2, contract 1.62): a tenant's cap, segments and reply profiles. The namespace is human-only: an apply whose manifest has a network section needs a human caller, and a service-account token meets 401 at the first network action.
