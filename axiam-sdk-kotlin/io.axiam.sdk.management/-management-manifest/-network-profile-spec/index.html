NetworkProfileSpec

data class NetworkProfileSpec(val segment: String, val sessionTimeoutSecs: Int, val terminationAction: RadiusTerminationAction? = null, val idleTimeoutSecs: JsonNullable<Int> = JsonNullable.Absent, val filterId: JsonNullable<String> = JsonNullable.Absent, val serviceType: JsonNullable<RadiusServiceType> = JsonNullable.Absent)

One segment's reply profile (network.profiles[], §27.6.2 item 1), keyed by its segment: a profile has no name or id of its own.

Every stated member is compared with the effective profile as the read returns it (§27.6.2 item 3, §36.3 rule 6): a stated sessionTimeoutSecs above the tenant's cap differs from the read, plan shows an Update, and the server refuses apply's replace with 403, which is the action's failure (apply stops; nothing is retried or lowered to the cap).
