NetworkSegmentSpec

data class NetworkSegmentSpec(val key: String, val site: String, val kind: NetworkSegmentKind, val name: String, val vlanId: Int, val rank: JsonNullable<Int> = JsonNullable.Absent, val filterIds: List<String>? = null, val enabled: Boolean? = null)

One network segment (network.segments[], §27.6.2 item 1).

The natural key is site + kind + name, where kind is the wire spelling access or quarantine (NetworkSegmentKind.ACCESS.wire); there is no zones spelling anywhere in a manifest. The three are the key and so never drift (§36.3 rule 4). Every other member is a field: unstated is silent (§27.6 rule 3) and, on an Update, carried from the read.

filterIds compares as a set (a reorder is NoChange); a segment that lists one Filter-Id twice is refused at plan, with zero wire calls. When the SDK writes it, it sends them in the order stated here.
