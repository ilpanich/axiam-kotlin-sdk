NamespaceScope

data class NamespaceScope(val orgId: UUID? = null, val tenantId: UUID? = null)

A per-handle override of the organization or tenant a route interpolates (CONTRACT.md §27.4 rule 3).

Both null means "inherit from the client", which is the ordinary case. A handle carrying an override is a new handle: inOrg(...) never mutates the one it was called on, so a scoped call cannot leak into unrelated code holding the same reference.
