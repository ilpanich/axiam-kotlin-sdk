class DirectoryApi

The directory management operations.

A view over the client that created it, not a connection: constructing one performs no I/O (§27.2 rule 1), so there is nothing to cache and nothing to close.

suspend fun delete()

Removes the configuration and its sync state. Directory accounts can no longer sign in with a password (there is no fallback to a local hash) and the sync job stops for the tenant; sessions, refresh tokens and passkeys they already hold keep working until they expire or an administrator deactivates the accounts. There is no unlink.

linkAccount
Link copied to clipboard
suspend fun linkAccount(body: LinkDirectoryAccount): DirectoryLinkResult

The directory resolves the entry from the account's own username; the caller supplies only the account. Marks the account, deletes its WebAuthn credentials and federation links, revokes its User-type certificates and then all its sessions and OAuth2 refresh tokens (TOTP is kept): the owner is signed out everywhere. Idempotent: an account already linked to that entry gets 200 with was_already_linked: true and the revocations run again.
