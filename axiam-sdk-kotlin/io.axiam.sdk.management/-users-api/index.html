listRoles

suspend fun listRoles(userId: UUID): List<RoleAssignment>

Lists a user's role assignments with the resource each is scoped to. Includes roles reaching the user through group membership, not only the ones assigned to them directly — that is what a user's effective role list is, and splitting the two would give a caller a list that disagrees with the authorization decision. Anything the role detail page's members panel shows as a group assignment therefore also appears here for each member.
