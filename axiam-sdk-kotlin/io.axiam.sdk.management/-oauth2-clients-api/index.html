class Oauth2ClientsApi

The oauth2_clients management operations.

A view over the client that created it, not a connection: constructing one performs no I/O (§27.2 rule 1), so there is nothing to cache and nothing to close.

createRegistrationToken
Link copied to clipboard
suspend fun createRegistrationToken(body: CreateRegistrationTokenRequest): CreateRegistrationTokenResponse

Mints the single-use credential RFC 7591 §1.2's protected registration profile requires. Gated on oauth2_clients:create rather than a permission of its own: a token minted here authorises exactly one registration, and a registration is strictly less than what that permission already confers (an administrator holding it can create any client directly, with any scopes, any audiences and any profile). A separate permission would suggest this is the more dangerous of the two, which it is not.
