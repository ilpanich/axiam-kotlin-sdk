parseSpMetadata
Link copied to clipboard
suspend fun parseSpMetadata(body: ParseSamlSpMetadata): SamlSpMetadataDraft

A parse to a draft, never a write. Takes exactly one of metadata_xml and metadata_url and returns what a registration of that SP could look like, the fingerprints of the certificates it carries and warnings. A URL is fetched once, through the SSRF guard (https only; loopback, private, link-local and cloud-metadata addresses refused; every redirect hop checked); a document is refused if it holds a DTD or entity declaration, is not UTF-8, is over 512 KiB, or is not exactly one EntityDescriptor with one SAML 2.0 SPSSODescriptor. Every refusal is a generic message that never carries the document, a status line or an address. The document's own signature is not evaluated.

Retires a next or an active credential and destroys its key. Retiring the active one with no successor stops SAML sign-on for the whole tenant at once — the incident response to a leaked key. Retiring a retired credential returns it unchanged and writes no audit row.
