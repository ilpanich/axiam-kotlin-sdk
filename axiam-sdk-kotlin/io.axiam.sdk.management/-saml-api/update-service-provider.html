A REPLACEMENT, not a patch: every field of the body is written, so read the current value first and copy() the parts you mean to keep (§27.4 rule 5).

An omitted member takes its default, not its stored value: enabled and sign_responses default to true, name_id_format to persistent, the other flags to false, certificates and slo_url / slo_binding to null, the lists to empty (§29.2).
