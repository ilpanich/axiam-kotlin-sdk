The changes toInput applies over a stream that was read (§32.2, contract 1.62). Every member defaults to "as read".

The four members ssf.update_stream requires (audience, deliveryMethod, eventsAllowed, receiverClientId) are plain nullable values: null keeps what was read. Every optional member is a JsonNullable: JsonNullable.Absent (the default) keeps what was read, JsonNullable.Value replaces it, and JsonNullable.Null is "none" — the key is left out of the body and null is never sent (§27.11 rule 5), which on a replacement clears the member (a description or endpoint_url back to null) or, for expectedUpdatedAt, replaces whatever is stored without the conditional.
