Page

data class Page<out T>(val items: List<T>, val total: Int, val offset: Int, val limit: Int)

One page of a paginated read (CONTRACT.md §27.4 rule 4).

total is the size of the whole set, not of items. That distinction is the entire reason this type exists rather than a bare List: an SDK that returned the list alone would let a caller conclude a tenant has 50 users because the first page held 50, and §27.4 rule 4 forbids exactly that.
