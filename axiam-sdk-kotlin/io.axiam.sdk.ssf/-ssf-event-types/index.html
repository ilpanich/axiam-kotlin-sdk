SsfEventTypes

object SsfEventTypes

The event-type URIs AXIAM transmits — the six CAEP / RISC events plus the two SSF stream events (CONTRACT.md §32.6).

Event types are OPEN: a SET whose type is not among these still verifies, and SecurityEvent.eventType carries it verbatim.
