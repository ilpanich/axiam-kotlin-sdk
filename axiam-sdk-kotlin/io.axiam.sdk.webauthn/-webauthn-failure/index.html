WebauthnFailure

enum WebauthnFailure : Enum<WebauthnFailure>

A ceremony failure a caller can say something useful about (CONTRACT.md §24.6b rule 5).

This SDK ships no linked-API helper — the JVM has no authenticator and §24.6b rule 2 forbids emulating one — but the classification is still required of it, because an Android app catching a CreateCredentialException has the same five outcomes and the same reason to want one vocabulary for them. classify takes either the platform's error name or the throwable itself.
